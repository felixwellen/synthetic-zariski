\begin{definition}
  Let $X$ be a type. An \textbf{entourage} of $X$ is an open subset of $X\times X$ containing the diagonal. 
\end{definition}

\begin{remark}
  Classically, a function $f:X \to Y$ is called \textbf{uniformly continuous} if for any entourage $E$ of $Y$, we have that $(f\times f)^{-1}(E)$ is an entourage of $X$. For the above definition of entourage, all functions are uniformly continuous in this sense. 
\end{remark}

With this definition of uniform continuity, we will do two things:
\begin{itemize}
  \item We will show that for the interval in \cite{synthetic-stone-duality}, this notion of uniform continuity matches with the expected $\epsilon,\delta$ version of uniform continuity. This will require us to recall some literature on synthetic topology and results on the interval in \cite{synthetic-stone-duality}. 
  \item We will also give a version of a classical result that says that if we have a uniformly continuous partial function from a dense subspace, we can extend this function. This will require us to recall some classical analytical results and check that they go trough in the setting of \cite{synthetic-stone-duality}. 
\end{itemize}

\subsection{Extensions of functions}
\begin{definition}
  Let $\iota : X \to Y$ be a map. A \textbf{relative entourage} of $X$ with respect to $\iota$ is an entourage of $X$ that is of the form $\iota^{-1}(E)$ for $E$ some entourage of $Y$. 

  A function $f: X \to Z$ is called \textbf{relatively uniformly continuous} if for any $F$ entourage of $Z$, we have that $f^{-1}(Z)$ is a relative entourage of $X$ with respect to $\iota$. 

  If $\iota$ is clear from context, we will ommit it. 
\end{definition}

\begin{definition}
  A subset $Q \subseteq X$ is called dense if for any $U\subseteq X$ open and inhabited, $U\cap Q$ is inhabited also. 
\end{definition}

Right now, in StoneCauchy.tex (\Cref{StoneCauchy}), we have a proof of the following statement using Cauchy sequences:
\begin{theorem}
  Let $Q \subseteq X$ be an overtly discrete dense subset of a compact Hausdorff space, and $Q\to Y$ be relatively uniformly continuous. Then there exists an unique extension $X \to Y$. 
\end{theorem}
