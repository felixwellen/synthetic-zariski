\section{Path- and $[0,1]$-contractibility}
In the setting of \cite{shulman-Brouwer-fixed-point} the shape is introduced as an operator, which forces a type to think that $\R$ is contractible. 
To be more precise, the shape is a localization at $\R$ in the sense of \cite{modalities}.
A type is $\R$-local if it cannot tell $\R$ from the unit type, and the shape of a type is the best $\R$-local approximation of that type. 
For example, the shape sends a topological CW-complex to its corresponding higher inductive type in HoTT. 
In the setting of SSD, it is more natural to look at the localization at $[0,1]$, which we justify in \Cref{localizationRImatch}. 
In order to make this note more self-contained, we will 
explain the notion of $[0,1]$-contractibility in simpler terms and
mention neither shape nor localization outside this section. 
\begin{definition}
  Let $C$ be a type. 
  A type $X$ is \textbf{$C$-local} if the constant map $X \to X^{C}$ is an equivalence. 
%  A type $Y$ is \textbf{$C$-contractible} if for all $C$-local types $X$ the constant map $X \to X^Y$ is an equivalence. 
  A type $Y$ is \textbf{$C$-contractible} if all $C$-local types are also $Y$-local. 
\end{definition}
\begin{lemma}\label{contractibleSigma}
  For any type $C$, the $C$-contractible types are closed under dependent sums. 
\end{lemma}
\begin{proof}
  Let $X$ be a $C$-local type, and let 
  $Y$ be a $C$-contractible type and 
  $Z(y)$ a family of $C$-contractible types over $Y$. 
  Then the constant map $X \to X^{\Sigma_{y:Y} Z(y)}$ factors as 
  $$
  X \simeq 
  X^Y\simeq 
  \Pi_{y:Y} X \simeq 
  \Pi_{y:Y} X^{Z(y)} \simeq 
  X^{\Sigma_{y:Y} Z(y)} 
  $$
\end{proof}
\begin{lemma}\label{retractContractible}
  Let $Y$ be a retract of $C$. 
  Then $Y$ is $C$-contractible.
\end{lemma}
\begin{proof}
  Let $i: Y \to C,  r:C \to Y$ satisfy $r\circ i = id_Y$. 
  Let the constant map $X \to X^C$ have the inverse $e:X^C\to X$. 
  We claim that $e\circ X^r: X^Y \to X$ is the inverse of the constant map $X \to X^Y$. 
  We need to show that for any $f:X^Y,y:Y$ we have $f y = e(f \circ r)$. 
  And indeed $$f y = f (r (i (y))) =(\lambda c . e(f\circ r))(i(y)) = e(f\circ r).$$ 
\end{proof}

\begin{remark}\label{contractibleVSconnected}
  By \Cref{IntermediateValue}, every function $[0,1]\to 2$ is constant and hence $2$ is $[0,1]$-local. 
  Thus if a type $X$ is $[0,1]$-contractible, it is connected in the sense that every map $X \to 2$ is constant. 
  The converse is not true. For example, for $\mathbb S^1$ the circle as higher inductive type, any map $\mathbb S^1 \to 2$ is constant. But $\mathbb S^1$ is not $[0,1]$-contractible: a cohomological argument \parencite[3.4.4.ii]{ssd-cohomology-draft} shows that $\mathbb S^1$ is $[0,1]$-local, but not every map $\mathbb S^1 \to \mathbb S^1$ is constant. 
\end{remark}

\begin{definition}
  Let $A$ be a type. For $a,b:A$, a \textbf{path} from $a$ to $b$ is a map $\gamma:[0,1]\to A$ with $\gamma(0) = a,\gamma(1) = b$. 
  $A$ is called \textbf{path-connected} if for any $a,b:A$ there merely exists a path from $a$ to $b$.
  $A$ is called \textbf{path-contractible} if we have a function that assigns to each $a,b:A$ a path from $a$ to $b$. 
  %Note difference with \exists and \Sigma
\end{definition} 
\begin{example}
  The topological circle is path-connected, but not path-contractible. 
\end{example}
\begin{lemma}\label{pathContractibleToLocalizationContractible}
  Any inhabited path-contractible type is $[0,1]$-contractible. 
\end{lemma}
\begin{proof}
  Let $X$ be $[0,1]$-local and $A$ path-contractible and inhabited. As we are showing a proposition, we may assume $a:A$. We claim that $\mathrm{ev}_a:X^A\to X$ is an inverse of the constant map $X \to X^A$. 
  This requires us to show that for any $f:X^A, b:A$ we have $f(a) = f(b)$. 
%  Clearly we have $ev_a\circ c = id_X$. To see that $c\circ ev_a = id_{X^A}$, we need to show that $\Pi_{f:X^A,b:A}(f(b) =f(a))$. 
  %Let $f:X^A$ and $b:A$. 
  By path-contractibility we have $\gamma:[0,1]\to A$ with $\gamma(0) = a,\gamma(1) = b$. 
  By $[0,1]$-locality, $f\circ \gamma : [0,1] \to X$ equals some constant path at $x:X$. 
  In particular, we have $f(a) = f(\gamma(0)) = x = f(\gamma(1)) = f(b)$ as required. 
\end{proof}
We shall see in the rest of this note that the converse to \Cref{pathContractibleToLocalizationContractible} is false. % being $[0,1]$-contractible does not make a type path-contractible. 
%We conclude this section by mentioning the helpful notion of convexity: 
\begin{definition}
  Let $X\subseteq \R^n$. $X$ is called \textbf{convex} if for any $x,y:\R^n$ and $a,b:[0,1]$ with $a+b = 1$, we have $X(x) \wedge X(y) \to X(ax+by)$. 
\end{definition}
\begin{remark}\label{ConvexInhabitedToContractible}
Using the path $t\mapsto ty + (1-t)x$, it can be shown that any convex type is path-contractible. 
Hence if a convex type is inhabited, it is also $[0,1]$-contractible by \Cref{pathContractibleToLocalizationContractible}.
\end{remark}

\begin{remark}\label{localizationRImatch}
  A type is $C$-contractible if and only if its localization at $C$ as in \cite{modalities} is contractible. 
  Instead of considering localization at $\R$ as in \cite{shulman-Brouwer-fixed-point}, in the setting of SSD, we study the shape as localization at $[0,1]$. 
  By \Cref{ConvexInhabitedToContractible}, $\R$ is $[0,1]$-contractible. Note that $[0,1]$ is a retract of $\R$, as witnessed by inclusion and the function $x \mapsto \max(0,\min(1,x))$. Hence by \Cref{retractContractible}, $[0,1]$ is $\R$-contractible. 
  Hence the $\R$-local and $[0,1]$-local types agree and so do the localizations at $\R$ and at $[0,1]$. 
\end{remark}
