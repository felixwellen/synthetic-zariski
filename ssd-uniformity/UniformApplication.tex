\begin{remark}
  Recall from \parencite[Example 1.8]{synthetic-stone-duality} there is a Stone space $\Noo:\Stone$ such that $2^\Noo= \N_{(co)fin}$, the Boolean algebra of finite and cofinite subsets of $\N$. There is a dense embedding $\iota:\N \hookrightarrow \Noo$, and there is a point $\infty :\Noo$ such that any decidable containing $\infty$ is cofinite. Therefore any open cover of $\Noo$ contains at least one cofinite subset. 

  For $X$ any type, note that a sequence $x:\N \to X$ is uniformly continuous relative to $\iota$ if and only if for any entourage $E$ of $X$ there is a cofinite subset $C: 2^\Noo$ such that whenever $n,m:C$ we have $(x_n,x_m)\in E$. As cofinite subsets are of the form $\N_{\geq N}$ for some $N:\N$, we can see that such sequences are exactly the Cauchy sequences. It follows from \Cref{Completeness} that any compact Hausdorff space is Cauchy complete.

\end{remark}
