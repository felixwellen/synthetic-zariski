The first motivating question behind this article is whether synthetic algebraic geometry admits a notion similar to the coherent sheaves in classic algebraic geometry.
Coherent sheaves share properties with finite dimensional vector spaces and appear for example in Serre-Duality.
To prove a basic version of the Serre-Duality Theorem (following e.g.\ \cite{Hartshorne}) which covers useful examples the following properties are essential:
\begin{enumerate}[(i)]
\item Coherent sheaves on a scheme $X$ form an abelian category.
\item Locally free sheaves are coherent.
\item There should be an abelian category $\mathcal{A}$ that contains all cohomology modules $H^i(X,\mathcal F)$ of a coherent sheaf $\mathcal F$, such that the dualization functor given by $\Hom_R(\argmhole,R)$ is exact on $\mathcal{A}$.
\end{enumerate}
For a non-trivial scheme (ii) can only be the case if the base is coherent (which would be a consequence of being noetherian). In synthetic algebraic geometry, we usually do not use (module-) sheaves.
Instead, we work with \emph{bundles} on a type $X$ which are just maps $X\to \Mod{R}$.
Also, we usually just restrict the target type $\Mod{R}$, to get more specific bundles.
So a convient solution to the problem above would be a subcategory of the category of $R$-modules, which contains at least finite free modules over the base ring $R$ and behaves well with respect to dualization.

Since the base ring in synthetic algebraic geometry is not coherent, we can not mimic the classical definition of coherent sheaves.
It turned already out in \cite{diffgeo-article} that there is a duality between finitely presented $R$-modules and the dual concept of finitely \emph{co}presented $R$-modules. For the latter, we really just ask for the existence of the dual of a finite presentation, which amounts to asking that a module is merely the kernel of a matrix.
In this article we extend this duality to \emph{finitely adequate} $R$-modules,
which we define as $R$-modules that are merely the kernel of a linear map between finitely presented $R$-modules.
These finitely adequate modules turn out to form an abelian category with a lot of good and surprising properties:
\begin{itemize}
\item Dualization is an anit-equivalence.
\item The finitely adequate $R$-modules are the free abelian category on the finite free $R$-modules \rednote{Do we actually state that somewhere?}.
\item If $A,B$ are finitely adequate, $\Hom_R(A,B)$ is finitely adequate.
\item The double dual of the tensor product is a tensor product \rednote{formulation}.
\item The injective modules are exactly the finitely presented modules and projective modules are exactly the finitely copresented modules.
\item Finitely adequate $R$-modules are closed under extensions (inside $\Mod{R}$).
\end{itemize}
By now, we know however from work building on this article, that finitely adequate modules are not a solution to the problem sketched above, since cohomology of finitely adequate bundles on a projective scheme is not finitely adequate in general.

In \cite{diffgeo-article} a definition of tagent spaces at any point of a general type was defined.
For finitely adequate $R$-modules -- due to a property we call infinitesimally linear -- we can show that there is an $R$-module structure on any tangent space and, surprisingly, any finitely adequate $R$-module is isomorphic to its tangent space at 0. We call $R$-modules with this property \emph{tangential} and study them in Section 1.
