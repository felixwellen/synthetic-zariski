The first motivating question behind this article is, if synthetic algebraic geometry admits a notion similar to the coherent sheaves in classic algebraic geometry.
Coherent sheaves share properties with finite dimensional vector spaces and appear for example in Serre-Duality.
To prove a basic version of the Serre-Duality Theorem (following e.g.\ \cite{Hartshorne}) which covers useful examples the following properties are essential:
\begin{enumerate}[(i)]
\item Coherent sheaves on a scheme $X$ form an abelian category.
\item Locally free sheaves are coherent.
\item There should be an abelian category $\mathcal{A}$ that contains all cohomology modules $H^i(X,\mathcal F)$ of a coherent sheaf $\mathcal F$, such that the dualization functor given by $\Hom_R(\argmhole,R)$ is exact on $\mathcal{A}$.
\end{enumerate}
For a non-trivial scheme (ii) can only be the case if the base is coherent (which would be a consequence of being noetherian).

Since the base ring in synthetic algebraic geometry is not coherent, we can not mimic the classical definition of coherent sheaves.
To keep things simple, we can move away from sheaves and ask instead, if there is a reasonable abelian category which contains at least finite free modules over the base ring $R$ and behaves well with respect to dualization.
It turned already out in \cite{diffgeo-article} that there is a duality between finitely presented $R$-modules and the dual concept of finitely \emph{co}presented $R$-modules. For the latter, we really just ask for the existence of the dual of a finite presentation, which amounts to asking that a module is merely the kernel of a matrix.
