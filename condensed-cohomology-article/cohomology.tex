This section leverage Scott continuity to compute cohomology for Stone spaces and compact Hausdorff spaces. In \Cref{first-cohomology-stone-chaus} we study the first cohomology groups with (not necessarily abelian) overtly discrete coefficients. We show they vanish for Stone spaces, and explain how they can be computed for compact Hausdorff spaces $C$ using cocycles for a given cover of $C$ by a Stone space. In \Cref{vanishing-stone} and \Cref{cech-sheaf-agree-section} we extend these results to higher cohomology groups. Then in \Cref{interval-acyclic} we prove that the interval is acyclic in the sense that its cohomology with overly discrete coefficient vanish (\Cref{cohomology-I}). Recall that by \Cref{overtly-discrete-countably-presented}, overtly discrete coefficients are the same as countably presented coefficients.



\subsection{Non-abelian cohomology for Stone spaces and compact Hausdorff spaces}
\label{first-cohomology-stone-chaus}

In \Cref{non-abelian-cech} we define the \v{Cech} cohomology group $\check{H}^1(X,Y,G)$ for any type $X$ with for each $x:X$ an inhabited type $Y(x)$ and a group $G(x)$. We then study these groups in the context of plain HoTT, and show they agree with regular cohomology in favorable situations. The goal of the present section is to apply these results to the cohomology of Stone spaces and compact Hausdorff spaces in synthetic Stone duality. First we extend Scott continuity from maps to \v{C}ech cohomology groups.

\begin{lemma}\label{first-cech-scott-continuity}
Assume given a Stone space $S$ and for each $x:S$ a tower of Stone spaces $(T_k(x))_{k:\N}$ with an overly discrete group $G(x)$. Write $T(x) =\mathrm{lim}_k\, T_k(x)$. Then $\check{H}^1(S,T,G) = \mathrm{colim}_k\, \check{H}^1(S,T_k,G)$.
\end{lemma}

\begin{proof}
We use Propositions \ref{scott-continuity-right} and \ref{scott-continuity-left} to show e.g.\ that $\Pi_{x:S}\, G(x)^{T(x)^2} = \mathrm{colim}_k\, \Pi_{x:S}\,G(x)^{T_k(x)^2}$. We have similar formulas for all the data used in defining cocycles and coboundaries, which allows to conclude. We omit the details.
\end{proof}

Now we can use the approximation of any surjection between Stone spaces as a limit of maps merely having section (\Cref{finite-approximation-stone-surjection-cohomology}) to conclude the vanishing of the appropriate \v{C}ech cohomology groups.

\begin{lemma}\label{cech-vanishing-first-stone}
Assume given a Stone space $S$ and for each $x:S$ an inhabited Stone spaces $T(x)$ with an overtly discrete group $G(x)$. Then $\check{H}^1(S,T,G) = 0$.
\end{lemma}

\begin{proof}
By \Cref{finite-approximation-stone-surjection-cohomology}, we get for each $x:S$ a tower of Stone spaces $(T_k(x))_{k:\N}$ such that $\mathrm{lim}_k\,T_k(x) = T(x)$ and we merely have $\Pi_{x:S}\,T_k(x)$ for all $k:\N$.

Then by \Cref{first-cech-scott-continuity} we have that $\check{H}^1(S,T,G) = \mathrm{colim}_k\,\check{H}^1(S,T_k,G)$, and by \Cref{first-cech-has-section-vanish} we have that $\check{H}^1(S,T_k,G) = 0$ for all $k:\N$ so we can conclude.
\end{proof}

Now using results from \Cref{non-abelian-cech}, we conclude the vanishing of the usual cohomology groups for Stone spaces, and that \v{C}ech cohomology agree with usual cohomology for compact Hausdorff spaces.

\begin{proposition}\label{vanishing-first-stone}
Assume given a Stone space $S$ and for each $x:S$ an overtly discrete group $G(x)$. Then $H^1(S,G) = 0$.
\end{proposition}

\begin{proof}
Let us consider $\alpha:H^1(S,G)$. By local choice there is $T(x)$ an inhabited Stone space depending on $x:S$ such that $\pi_S^*(\alpha) = 0$, so that $\alpha$ is in $H^1(S,T,G)$. But by \Cref{non-abelian-chech-is-sheaf-generic} we have $H^1(S,T,G) = \check{H}^1(S,T,G)$ and by \Cref{cech-vanishing-first-stone} we have $\check{H}^1(S,T,G) = 0$, so that $\alpha=0$.
\end{proof}

\subsection{Vanishing of higher cohomology for Stone spaces}
\label{vanishing-stone}

The goal of this section is to extend \Cref{vanishing-first-stone} to higher cohomology groups. We proceed by induction on the cohomology index, which requires to strengthening the result to delooping of overtly discrete abelian groups commuting with Stone-indexed $\Pi$-types. First we present some preliminary results and definitions that works in plain HoTT.

%To be more specific, we will show in

\begin{definition}
  Assume given $n:\N$ and a type $S$ with for each $x:S$ an abelian group $A(x)$. We write $\epsilon_n^{S,A}$ for the canonical map from $\K(\Pi_{x:S}A(x),n)$ to $\Pi_{x:S}\,\K(A(x),n)$.
\end{definition}

Our goal is then to show that $\epsilon_n^{S,A}$ is an equivalence when $S$ is Stone and each $A(x)$ is overtly discrete. First an easy remark.

\begin{lemma}\label{ev-eq-acyclic}
  Assume given $n\geq 1$ and a type $S$ with for each $x:S$ an abelian group $A(x)$. If $\epsilon_n^{S,A}$ is an equivalence, then $H^n(S,A) = 0$. 
\end{lemma}

\begin{proof}
  If $\epsilon_n^{S,A}$ is an equivalence then
  $H^n(S,A) = \propTrunc{\Pi_{x : S}\, \K(A(x),n)}_0 = \propTrunc{\K(\Pi_{x : S} A(x) , n)}_0$
  which is contractible because $n\geq 1$. 
\end{proof}

\begin{lemma}\label{ev-embedding}
  Assume given $n:\N$ and a type $S$ with for each $x:S$ an abelian group $A(x)$. If $\epsilon_n^{S,A}$ is an equivalence, then $\epsilon_{n+1}^{S,A}$ is an embedding. 
\end{lemma}

\begin{proof}
  The source is pointed and connected, so it is enough to prove the induced map
  \[\Omega(\K(\Pi_{x:S}A(x),n+1)) \to \Omega(\Pi_{x:S}\, \K(A(x),n+1))\]
  is an equivalence. But this map is equal to the canonical map
  \[\epsilon_n^{S,A} : \K(\Pi_{x:S}A(x),n) \to \Pi_{x:S}\,\K(A(x),n)\]
  which is assumed to be an equivalence.
\end{proof} 

\begin{lemma}\label{acyclic-ev-surjective}
  Assume given $n\geq 1$ and a type $S$ with for each $x:S$ an abelian group $A(x)$. If $H^n(S,A) = 0$, then $\epsilon_{n}^{S,A}$ is a surjection.
\end{lemma}

\begin{proof}
  Since $\K(\Pi_{x:S}A(x),n)$ is inhabited, it is enough to show that $\Pi_{x : S}\, \K(A_x,n)$ is $0$-connected, 
  which exactly means that $H^{n}(S,A)=0$. 
\end{proof}

\begin{theorem}\label{eilenberg-exponentials}
Assume given $n:\N$ and a Stone space $S$ with for each $x:S$ an overtly discrete abelian group $A(x)$. Then the $\epsilon_n^{S,A}$ is an equivalence.
\end{theorem}

\begin{proof}
  We proceed by induction on $n$. If $n=0$, this is the identity map. 
  
  Now assume the result holds for some $n:\N$.
  
  By this induction hypothesis and \Cref{ev-embedding}, we have that $\epsilon_{n+1}^{S,A}$ is an embedding. We just need to prove that it is surjective to conclude, and by \Cref{acyclic-ev-surjective}, it's sufficient to show that $H^{n+1}(S,A) = 0$. For $n=0$ this is the abelian version of \Cref{vanishing-first-stone}. 
  
  Now we assume $n\geq 1$. Assume given $\alpha:H^{n+1}(S,A)$, by local choice there exists a family of inhabited Stone spaces $(T(x))_{x:S}$ such that $\pi^*(\alpha) : H^{n+1}(\Sigma_{x:S}T(x), A\circ\pi)$ is $0$, where $\pi:\Sigma_{x:S}\,T(x)\to S$ is the first projection. Consider factorisation of $\pi^*$ as
  \[ H^{n+1}(S,A)\to H^{n+1}(S,x\mapsto A(x)^{T(x)}) \to H^{n+1}(\Sigma_{x:S}T(x), A\circ\pi). \]
  We will show that both maps are injective, which will imply $\alpha=0$.

\begin{itemize}
 \item For the first map, for each $x:S$ we define an abelian group $L(x)$ by the exact sequence
  \[  0\to A(x) \to A(x)^{T(x)} \to L(x) \to 0. \]
The long exact cohomology sequence then gives exactness of
\[ H^n(S,L)\to H^{n+1}(S,A)\to H^{n+1}(S,x\mapsto A(x)^{T(x)}).\]
By TODO we get that $L(x)$ is overtly discrete. So by the induction hypothesis and \Cref{ev-eq-acyclic} we have that $H^n(S,L)=0$. Then the first map in the factorisation is indeed injective.
\item  By the induction hypothesis and \Cref{ev-embedding}, for all $x:S$ the map $\epsilon_{n+1}^{T(x),A(x)}$ is an embedding. So the second map in the factorisation is indeed injective. 
\end{itemize}
\end{proof}

\begin{corollary}\label{vanishing-cohomology-stone}
Assume given $n\geq 1$ and a Stone space $S$ with for each $x:S$ an overtly discrete abelian group $A(x)$. Then $H^n(S,A) = 0$.
\end{corollary}



\subsection{\v{C}ech cohomology for compact Hausdorff spaces}
\label{cech-sheaf-agree-section}

Next lemma show that cohomology interact well with \v{C}ech cover. It will be used later to prove that cohomology and \v{C}ech cohomology agree.

\begin{lemma}\label{inductive-definition-cohomology}
Assume given $X$ a type with a \v{C}ech cover $S$ and $A(x)$ an overtly discrete abelian group depending on $x:X$. Then for all $n:\N$ we have an exact sequence:
\[H^{n}(X,\lambda x.A(x)^{S(x)}) \to H^{n}(X,L)\to H^{n+1}(X,A)\to 0\]
natural in $A$, where $L(x) = A(x)^{S(x)}/A(x)$.
\end{lemma}

\begin{proof}
From the long exact cohomology sequence we just need to prove that $H^{n+1}(X,\lambda x.A(x)^{S(x)}) = 0$. But by \Cref{eilenberg-exponentials} we have that $\Pi_{x:X}K(A(x)^{S(x)},n+1) = \Pi_{x:X}K(A(x),n+1)^{S(x)}$ so that $H^{n+1}(X,\lambda x.A(x)^{S(x)}) = H^{n+1}(\Sigma_{x:X}S(x),A\circ \pi_S)$ so it is $0$ by \Cref{vanishing-cohomology-stone}.
\end{proof}

Next definition will be used for \v{C}ech cover.

\begin{definition}\label{dfnCech}
Assume given a type $X$ with $Y(x)$ an inhabited type and $A(x)$ an abelian group both depending on $x:X$. We define its its \v{C}ech sequence $\check{C}(X,Y,A)$ as:
\[\Pi_{x:X}A(x)^{Y(x)} \overset{\delta_0}{\longrightarrow} \Pi_{x:X}A(x)^{Y(x)^2} \overset{\delta_1}{\longrightarrow} \Pi_{x:X}A(x)^{Y(x)^3} \overset{\delta_3}{\longrightarrow} \cdots \]
with:
\[\delta_n(\alpha)_x(y_0,\cdots,y_n) = \Sigma_{i=0}^n (-1)^i \alpha(y_0,\hdots,\hat{x_i},\hdots,y_n)\]
We have that $\delta_{n+1} \circ \delta_n = 0$.

We define its $n$-th \v{C}ech cohomology group $\check{H}^n(X,Y,A)$ as the $n$-th cohomology group of this chain complex.
\end{definition}

We prove a generic result about \v{C}ech sequence.

\begin{lemma}\label{cech-coefficient-lemma}
Assume given a type $X$ with $Y(x)$ a type and $A(x)$ an abelian group both depending on $x:X$. Then $\check{H}^n(X,Y,\lambda x.\, A(x)^{Y(x)})=0$ for all $n\geq 1$.
\end{lemma}

\begin{proof}
Indeed assume given:
\[\alpha : \Pi_{x:X} Y(x)^{n+1}\to A(x)^{Y(x)}\]
such that $\delta(\alpha) = 0$, i.e. for all $x:X$ and $y_0,\hdots, y_{n+1},y:Y(x)$ we have that:
\[\Sigma_{i=0}^{n+1}(-1)^i\alpha(x,y_0,\hdots,\widehat{y_i},\hdots ,y_{n+1},y) = 0\]
Then we define:
\[\beta : \Pi_{x:X} Y(x)^{n}\to A(x)^{Y(x)}\]
\[\beta(x,y_0,\hdots,y_{n-1},y) = (-1)^n\alpha(x,y_0,\hdots,y_{n-1},y,y)\]
and then:
\[\delta(\beta)(x,y_0,\hdots,y_{n},y) = (-1)^n\Sigma_{i=0}^{n} (-1)^i \alpha(x,y_0,\hdots,\hat{y_i},\hdots,y_n,y,y) \]
\[= \alpha(x,y_0,\hdots,y_n,y)\]
so $\delta(\alpha) = 0$.
\end{proof}

\begin{lemma}\label{long-exact-cech-cohomology}
Assume given $X$ a type with $S$ a \v{C}ech cover and a short exact sequence of overtly discrete abelian group:
\[0\to A(x)\to B(x)\to C(x)\to 0\]
depending on $x:X$. Then there is a long exact sequence of \v{C}ech cohomology groups:
\[\check{H}^0(X,A) \to\check{H}^0(X,B) \to\check{H}^0(X,C) \to\check{H}^1(X,A) \to\check{H}^1(X,B) \to\check{H}^1(X,C) \to\cdots \]
Moreover this long exact sequence is natural in the short exact sequence.
\end{lemma}

\begin{proof}
We just use the fact that all elements $\Sigma_{x:X} T_x^{k+1}$ in the \v{C}ech complex are Stone spaces, so a short exact sequence of overtly discrete abelian group induces a short exact sequence of \v{C}ech complexes by \Cref{vanishing-cohomology-stone}, and then we use the long exact cohomology sequence induced by such a short exact sequence of complexes.
\end{proof}

\begin{lemma}\label{inductive-definition-cech-cohomology}
Assume given $X$ a type with $S$ a \v{C}ech cover and $A(x)$ an overtly discrete abelian group depending on $x:X$.

Then for all $n:\N$ we have an exact sequence:
\[\check{H}^{n}(X,\lambda x.\, A(x)^{S(x)}) \to \check{H}^{n}(X,L)\to \check{H}^{n+1}(X,A)\to 0\]
natural in $A$ where $L(x)=A(x)^{S(x)}/A(x)$.
\end{lemma}

\begin{proof}
By \Cref{long-exact-cech-cohomology}, it is enough to prove $\check{H}^{n+1}(X,\lambda x.\, A(x)^{S(x)}) = 0$. This is \Cref{cech-coefficient-lemma}.
\end{proof}

\begin{theorem}\label{cech-and-sheaf-agree}
Assume given $X$ a type with $S$ a \v{C}ech cover and $A(x)$ an overtly discrete abelian group depending on $x:X$.

Then we have a natural isomorphism $H^n(X,A) = \check{H}^n(X,S,A)$
\end{theorem}

\begin{proof}
We proceed by induction on $n$. For $n=0$ we need to prove that the type of maps:
\[\{\alpha:\Pi_{x:X}A(x)^{S(x)}\ |\ \forall x,s_0,s_1.\, \alpha_x(s_0)=\alpha_x(s_1)\}\]
is naturally isomorphic to $\Pi_{x:X}A(x)$. This is immediate from $S(x)$ being inhabited sets.

For the inductive step we use \Cref{inductive-definition-cohomology} and \Cref{inductive-definition-cech-cohomology}. Naturality comes from the naturality of the long exact sequences.
\end{proof}



\subsection{The unit interval is acyclic}
\label{interval-acyclic}
This section extends \cite[Section 5.4]{synthetic-stone-duality}. 
\begin{remark}
  \rednote{SSD}
  Recall from \parencite[Section 4.4]{synthetic-stone-duality} that for each $n:\N$, we can define $cs_n: 2^n \to Q$ by $cs_n(\alpha) = \sum\limits_{i<n} \frac{\alpha(i)}{2^{i+1}}$. And for $\I = [0,1]$ the interval of Cauchy or Dedekind reals, we can define $cs: 2^\N \to \I$ by $cs(\alpha) = \lim\limits_{n\to\infty} cs_n(\alpha)|_n$. This function witnesses that $\I$ is compact Hausdorff. 
\end{remark}

\begin{definition}
  \rednote{Combinatorics}
  Fix $n:\mathbb N$. Consider the simplicial complex $\mathbb I_n^\sim$ whose vertices are elements of $Fin(2^n)$ and only contains simplices of numbers whose pairwise distance is $\leq 1$. 
  We denote $\mathbb I_n^{\sim k}$ for the set of elementary $k$-chains of $\mathbb I_n^\sim$ as in \parencite[Def VI.2.1]{EilenbergSteenrod}.
\end{definition}   

\begin{remark}\label{description-Cn-simn}
  \rednote{SSD}
  Note that $\mathbb I_n^{\sim k}$ is in equivalence with 
  the type of $k+1$-tuples of binary sequences in $2^n$ such that for any $a,b:2^n$ in the tuple, we have 
  $|cs_n (a) -cs_n(b) |\leq\frac1{2^n}$. 
  Note that there are at most two such sequences, and that 
  $$\Sigma_{x : \mathbb I} (cs^{-1}(x))^{k+1} = \lim_{n} \mathbb I_n^{\sim k}$$
\end{remark}
\begin{definition}
  \rednote{Combinatorics}
  We define the ordered chain complex \parencite[Def VI.2.3]{EilenbergSteenrod} $C_k$ associated to $\mathbb I_n^{\sim}$ as follows: for each $k$, the group $C_k$ is given by the free abelian group on $\mathbb I_n^{\sim k}$, and the map $\partial_k: C_k\to C_{k-1}$ is induced by 
  $$\partial_k(a_0,\cdots , a_k) = \sum\limits_{i=0}^k (-1)^i(a_0,\cdots \widehat{a_i},\cdots a_k).$$

  We define also the alternating chain complex $D_k$ associated to $\mathbb I_n^\sim$: for each $k$, the group $D_k$ is obtained as quotient of $C_k$ by setting
  \begin{align*}
    (a_0, \cdots a_k) - sgn(\sigma) (a_{\sigma(0)} , \cdots a_{\sigma(k)})=0 &\text{ for all permutations } \sigma \text{ on } \mathbb N_{\leq k} \\
    (a_0, \cdots a_k) = 0 &\text{ whenever } a_i = a_j \text{ for some } i\neq j
  \end{align*}
  Where $sgn(\sigma)$ is the sign of the permutation $\sigma$. 
\end{definition}
Using \parencite[Lemmas VI.6.5 and VI.6.6]{EilenbergSteenrod}, one can see that the alternating chain complex defined above agrees with the one defined in \parencite[Def VI.6.8]{EilenbergSteenrod},  

\begin{remark}\label{RmkTrivialDk}
  \rednote{SSD}
As $\mathbb I_n^{\sim k}$ contains at most 2 sequences, for $k\geq 2$, $D_k$ is trivial. 
\end{remark}

\begin{definition}\label{DfnExactSequence}
  \rednote{Combinatorics}
For a given group $G$ and natural number $n$, we are interested in the following sequence:
\begin{equation}\label{EqSequence}
    \begin{tikzcd}
      0 \arrow[r,"d_{-2}"]& G \arrow[r,"d_{-1}"]& 
      G^{\mathbb I_n^{\sim 0}  } \arrow [r , "d_0"]     & 
      G^{\mathbb I_n^{\sim 1}  } \arrow [r , "d_1"]     & 
      \cdots                     \arrow [r , "d_{k-2}"] & 
      G^{\mathbb I_n^{\sim k-1}} \arrow [r , "d_{k-1}"] & 
      G^{\mathbb I_n^{\sim k  }} \arrow [r , "d_k"]     & 
      G^{\mathbb I_n^{\sim k+1}} \arrow [r , "d_{k+1}"] & 
      \cdots
    \end{tikzcd}
  \end{equation}
  with $d_k(f)(a_0, \cdots , a_k) = \sum\limits_{i=0}^k (-1)^i f(a_0 , \cdots, \widehat {a_i} , \cdots, a_k)$. Note that in general, this sequence is a sequence of pointed sets. If $G$ is an abelian group, this is a sequence of group morphisms. 
\end{definition}

\begin{lemma}\label{LemmaExactnessIntervalApproxFirstTerms}
  \rednote{Combinatorics}
  For any group $G$, the sequence in \Cref{EqSequence} is exact at 
  $G,G^{\mathbb I_n^{\sim 0}},$ and $G^{\mathbb I_n^{\sim 1}}$.
\end{lemma}
\begin{proof}
  \begin{itemize}
    \item
  As $\mathbb I_n$ is inhabited, $G \to G^{\mathbb I_n^{\sim0}}$ is injective, thus we have exactness at $G$. 
%
\item 
Suppose $\alpha : \mathbb I_n \to G$ is a cocycle. 
  Then $\alpha(a) = \alpha(b)$ whenever $|a - b|\leq 1$. 
%  By \Cref{RmkConstantIfRespsimn}, $\alpha$ is constant.
  But as all elements of $Fin(2^n)$ are related by steps of size $1$, $\alpha$ is constant.
  Thus we have exactness at $G^{\mathbb I_n^{\sim 0}}$. 
%
\item
  If $\alpha : \mathbb I_n^{\sim 1} \to G$ is a cocycle, then 
  $\alpha(a,a) = 0$ and $\alpha(a,b) = -\alpha(b,a)$ for all 
  $a,b: 2^n$. 
  Define 
  $\beta : \mathbb I_n^{\sim 0} \to G$ by 
 $$\beta(a) = \alpha(a-1,a) +  \alpha (a-2,a-1) + \cdots + \alpha(0,1).$$
  Then $\beta(a) - \beta(a) = 0 = \alpha(a,a)$, 
  and $\beta(a+1) - \beta(a) = \alpha(a,a+1)$, and hence 
  $\beta(a)-\beta(a+1) = -\alpha(a,a+1) = \alpha(a+1,a)$. 
  Thus $d_0(\beta) $ and $ \beta$ agree on all possible inputs of $\mathbb I_n^{\sim 1}$
  and we have exactness at $G^{\mathbb I_n^{\sim1}}$.
%
\end{itemize}
\end{proof}
 \begin{lemma}\label{LemmaExactnessIntervalApproxLaterTerms}
   \rednote{Combinatorics}
   For any abelian group $G$, the sequence in \Cref{EqSequence} is exact at $G^{\mathbb I_n^{\sim k}}$
  for $k\geq 2$. 
\end{lemma} 
\begin{proof}
  The sequence in \Cref{EqSequence} is given by applying $Hom_{Ab}(-,G)$ to the ordered chain complex $C_k$.
  By \parencite[Theorem VI.6.10]{EilenbergSteenrod}, this ordered chain complex is homotopy equivalent to the alternating chain complex $D_k$. As $D_k$ was trivial for $k\geq 2$ by \Cref{RmkTrivialDk}, $Hom_{Ab}(D_k,G)$ is also trivial.
  We conclude that the sequence in \Cref{EqSequence} is exact at $G^{\mathbb I_n^{\sim k}}$.
\end{proof}



\begin{lemma}\label{interval-connected}
  \rednote{SSD}
Given $I$ a finite type, any map from $\I$ to $I$ is constant.
\end{lemma}

\begin{proof}
We consider the map $p : 2^\N\to\I\to I$, by \Cref{factorisation-stone-finite} it factors through $2^n$ for some $n:\N$. 

Let us prove that for all $k:\N$, if the map factors through $2^{k+1}$ as $p_{k+1}$ then it factors through $2^k$. Consider $\alpha:2^k$, then since $p$ factors through $\I$, it respects $\sim_{k}$. So we have that $p(\alpha,1,0,0,\hdots) = p(\alpha,0,1,1,\hdots)$ so that $p_{k+1}(\alpha,0) = p_{k+1}(\alpha,1)$, and $p_{k+1}$ indeed factors through $2^k$, therefore so does $p$.

From this we get that $p$ factors through $2^0$, so it is indeed constant.
\end{proof}





\begin{theorem}\label{cohomology-I}
  \rednote{SSD + Combinatorics}
The unit interval is acyclic, in the sense that:

\begin{enumerate}[(i)]
\item Given $I$ an overtly discrete type, any map in $\I\to I$ is constant.
\item Given $G$ an overtly discrete group, we have that $H^1(\I,G) = 0$.
\item Given $A$ an overtly discrete abelian group, we have that $H^n(\I,A) = 0$ for $n\geq 1$.
\end{enumerate}
\end{theorem}

\begin{proof}
We prove each point as follows:

\begin{enumerate}[(i)]

\item Given a map $p:\I\to I$, we write $I=\mathrm{colim}_jI_j$ with $I_j$ finite. By \Cref{scott-continuity-chaus} we know that $p$ factors through $I_k$ for some $k$, but by \Cref{interval-connected} any map from $\I$ to $I_k$ is constant so $p$ is indeed constant.

\item Consider $cs:2^\N\to\I$ and the associated \v{C}ech cover $T$ of $\I$ defined by: 
\[T(x) = \Sigma_{y:2^\N} (x=_\I cs(y))\]
Then we have that $\mathrm{lim}_n\I_n^{\sim l} = \Sigma_{x:\I} T(x)^l$. By \Cref{LemmaExactnessIntervalApproxFirstTerms} and stability of exactness under sequential colimit, we have an exact sequences:
\[ \mathrm{colim}_n G^{\I_n} \to \mathrm{colim}_n G^{\I_n^{\sim2}}\to \mathrm{colim}_n G^{\I_n^{\sim3}}\]
By \cref{scott-continuity-left} this sequence is equivalent to
\[\Pi_{x:\I}G^{T(x)} \to  \Pi_{x:\mathbb{I}}G^{T(x)^2} \to  \Pi_{x:\mathbb{I}}G^{T(x)^3}\]
So it being exact implies that $\check{H}^n(\I,T,G) = 0$ for $n\geq 1$.
We conclude by \Cref{non-abelian-cech-and-sheaf-agree}.

\item Same as point (ii) using \Cref{cech-and-sheaf-agree} instead of \ref{non-abelian-cech-and-sheaf-agree} and \Cref{LemmaExactnessIntervalApproxLaterTerms} in addition to \ref{LemmaExactnessIntervalApproxFirstTerms}. 

\end{enumerate}
\end{proof}

We give an example of application, which justifies why we spend all the effort on the non-abelian case. Recall that a type $X$ is $\I$-local if the map $X\to X^\I$ is an equivalence.

\begin{lemma}\label{delooping-I-local}
  \rednote{SSD}
We have the following:

\begin{enumerate}[(i)]
\item Any overtly discrete type is $\I$-local.
\item Given $G$ an overtly discrete group, we have that $BG$ is $\I$-local.
\item Given $A$ an overtly discrete abelian group and $n:\N$, we have that $K(A,n)$ is overtly discrete.
\end{enumerate}
\end{lemma}

\begin{proof}
As follows:

\begin{enumerate}[(i)]
\item From \Cref{cohomology-I}(i).
\item Identity types in $BG$ are $G$-torsors, therefore they are $\I$-local by (i), so the map $BG\to BG^\I$ is an embedding. It is surjective by \Cref{cohomology-I}(ii).
\item By induction on $n:\N$, the case $n=0$ is point (i). Assume it holds for $n\geq 0$, then identity types in $K(A,n+1)$ are $K(A,n)$-torsors, therefore they are $\I$-local by induction hypothesis, so the map $K(A,n+1)\to K(A,n+1)^\I$ is an embedding. It is surjective by \Cref{cohomology-I}(iii).
\end{enumerate} 
\end{proof}

\begin{proposition}
  \rednote{SSD}
Assume given $X$ a type such that:

\begin{itemize}
\item $X$ is Postnikov complete (i.e. $\mathrm{lim}_k\propTrunc{X}_k = X$).
\item $\propTrunc{X}_0$ is overtly discrete.
\item For all $x:X$ and $n\geq 1$, we have that $\pi_n(X,x)$ is overtly discrete.
\end{itemize}
Then $X$ is $\I$-local.
\end{proposition}

\begin{proof}
By Postnikov completion it is enough to prove that $\propTrunc{X}_n$ is $\I$-local for all $n:\N$. We proceed by induction on $n:\N$. 

For $n=0$ this is \Cref{delooping-I-local}(i).

For $n=1$ we have a map $\propTrunc{X}_1\to \propTrunc{X}_0$, from the $n=0$ case we just need to prove its fibers are $\I$-local. But they merely are of the form $B\pi_1(X,x)$ for some $x:X$, so we conclude by \Cref{delooping-I-local}(ii). 

Assuming this holds for $n\geq 1$, we have a map $\propTrunc{X}_{n+1}\to \propTrunc{X}_n$. By the induction hypothesis we just need to prove its fibers are $\I$-local to conclude that $\propTrunc{X}_{n+1}$ is $\I$-local. But the fibers are merely of the form $K(\pi_{n+1}(X,x),n+1)$ for some $x:X$, so we conclude by \Cref{delooping-I-local}(iii). 
\end{proof}
