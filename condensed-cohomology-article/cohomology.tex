In this section, we leverage Scott continuity to compute cohomology for Stone spaces and compact Hausdorff spaces. In \Cref{first-cohomology-stone-chaus} we study the first cohomology groups with (not necessarily abelian) overtly discrete coefficients. We show they vanish for Stone spaces, and explain how they can be computed for compact Hausdorff spaces $C$ using cocycles for a given cover of $C$ by a Stone space. In \Cref{vanishing-stone} and \Cref{cech-sheaf-agree-section} we extend these results to higher cohomology groups. Then in \Cref{interval-acyclic} we prove that the interval is acyclic in the sense that its cohomology with overtly discrete coefficient vanish (\Cref{cohomology-I}). Recall that by \Cref{overtly-discrete-countably-presented}, overtly discrete coefficients are the same as countably presented coefficients.

\begin{remark}\label{familiarWithCohomology}
  We will assume familiarity with cohomology in homotopy type theory. So for a type $X$ with for each $x:X$ a group $G(x)$ the cohomology $H^n(X,G)$ is defined as the set truncation $\|\Pi_{x:X} K(G(x),n)\|_0$. 
  Here $K(G,n)$ refers to the $n$'th-delooping of the group $G$, that is the unique $n-1$-connected pointed $n$-type whose $n$'th loop space is $G$. Such a type exists for any group $G$ if $n=1$, and for abelian groups $G$ if $n>1$. 
  If $n=1$, we also denote the delooping $K(G,1) = BG$, and for $\alpha:BG$, we identify silently $\alpha$ with $\alpha = 1$, which is the equivalence between $BG$ and the type of $G$-torsors. 
  More on the cohomology can be found in \cite{evan-master-thesis}. Other helpful references include \cite{hott, warn2024, Sym, LicataFinster}.
\end{remark}


\subsection{Non-abelian cohomology for Stone spaces and compact Hausdorff spaces}
\label{first-cohomology-stone-chaus}

In this section we will show the vanishing of the non-abelian cohomology groups of Stone spaces with overtly discrete coefficients, and explain how to compute these cohomology groups for compact Hausdorff spaces. Our main tool will be non-abelian \v{C}ech cohomology, which we now introduce.

\begin{definition}\label{dfnCocycle}
Assume given a type $X$  and for each $x:X$ an inhabited type $Y(x)$ and a group $G(x)$.
\begin{itemize}
\item A cocycle is a $\delta:\Pi_{x:X}\,G(x)^{Y(x)^2}$ such that for all $x:X$ and $y_0,y_1,y_2:Y(x)$ we have $\delta_x(y_0,y_1)\cdot \delta_x(y_1,y_2) = \delta_x(y_0,y_2)$.
\item Two cocycles $\delta$ and $\delta'$ are called cohomologous if there exists $\gamma:\Pi_{x:X}\,G(x)^{Y(x)}$ such that for all $x:X$ and $y_0,y_1:Y(x)$ we have $\gamma_x(y_0)\cdot\delta_x(y_0,y_1) = \delta'_x(y_0,y_1)\cdot\gamma_x(y_1)$.
\end{itemize}
\end{definition}

\begin{definition}\label{dfnCechCohomology}
Assume given a type $X$  and for each $x:X$ an inhabited type $Y(x)$ and a group $G(x)$. 
\begin{itemize}
\item We define the non-abelian \v{C}ech cohomology $\check{H}^1(X,Y,G)$ as the quotient of cocycles by being cohomologous.
\item We define $H^1(X,Y,G)$ as $\{\alpha:H^1(X,G)\ |\ \pi^*(\alpha) = 1\}$ where $\pi$ is the projection $\Sigma_{x:X}\,Y(x)\to X$.
\end{itemize}
\end{definition}

\begin{lemma}\label{CechConditionEquivalentStatement}
  Let $X,Y,G,\pi$ be as above. For $\alpha : H^1(X,G)$, we have $\pi^*(\alpha) = 1$ if and only if there exists some $\beta:\Pi_{x:X}\alpha_x^{Y(x)}$. 
\end{lemma}
\begin{proof}
  Let $\alpha: \Pi_{x:X} BG(x)$. Then $\alpha \circ \pi : \Pi_{(x,y):\Sigma_XY} BG(x)$ equals $1$ iff for all $x:X, y:Y(x)$ we have $\alpha_x = 1$. In $BG$, we identify $\alpha_x =1 $ and $\alpha_x$. 
\end{proof}
The following result justifies the interest of this non-abelian \v{C}ech cohomology. The proof can be found as \Cref{non-abelian-chech-is-sheaf-generic} in \Cref{non-abelian-cech}. We did not include it in the core text as it is quite technical and works in plain HoTT, making it not so relevant to synthetic Stone duality, and of independent interest to homotopy type theorists.

\begin{proposition}
Assume given $X$ a type with $Y(x)$ an inhabited type and $G(x)$ a group both depending on $x:X$. Then $H^1(X,Y,G)=\check{H}^1(X,Y,G)$.
\end{proposition}

Now we are ready to work with Stone spaces and overtly discrete coefficients. First we extend Scott continuity from maps to \v{C}ech cohomology groups.

%In \Cref{non-abelian-cech} we define the \v{Cech} cohomology group $\check{H}^1(X,Y,G)$ for any type $X$ with for each $x:X$ an inhabited type $Y(x)$ and a group $G(x)$. We then study these groups in the context of plain HoTT, and show they agree with regular cohomology in favorable situations. The goal of the present section is to apply these results to the cohomology of Stone spaces and compact Hausdorff spaces in synthetic Stone duality. First we extend Scott continuity from maps to \v{C}ech cohomology groups.

\begin{lemma}\label{first-cech-scott-continuity}
Assume given a Stone space $S$ and for each $x:S$ a tower of Stone spaces $(T_k(x))_{k:\N}$ with an overly discrete group $G(x)$. %Write $T(x) =\mathrm{lim}_k\, T_k(x)$. 
Then $\check{H}^1(S,T,G) = \mathrm{colim}_k\, \check{H}^1(S,T_k,G)$.
\end{lemma}

\begin{proof}
We use Propositions \ref{scott-continuity-right} and \ref{scott-continuity-left} to show e.g.\ that $\Pi_{x:S}\, G(x)^{T(x)^2} = \mathrm{colim}_k\, \Pi_{x:S}\,G(x)^{T_k(x)^2}$. We have similar formulas for all the data used in defining cocycles and coboundaries, which allows to conclude. We omit the details.
\end{proof}

%Now we can use the approximation of any surjection between Stone spaces as a limit of maps merely having section (\Cref{finite-approximation-stone-surjection-cohomology}) to conclude the vanishing of the appropriate \v{C}ech cohomology groups.

Now we will show that the first \v Cech cohomology groups vanishes for Stone spaces. 

\begin{lemma}\label{cech-vanishing-first-stone}
Assume given a Stone space $S$ and for each $x:S$ an inhabited Stone spaces $T(x)$ with an overtly discrete group $G(x)$. Then $\check{H}^1(S,T,G) = 0$.
\end{lemma}

\begin{proof}
  By \Cref{finite-approximation-stone-surjection-cohomology}, we get for each $x:S$ a tower of Stone spaces $(T_k(x))_{k:\N}$ such that $\mathrm{lim}_k\,T_k(x) = T(x)$ and we merely have $\Pi_{x:S}\,T_k(x)$ for all $k:\N$. By \Cref{first-cech-has-section-vanish} it follows that $\check{H}^1(S,T_k,G) = 0$ for all $k:\N$ so we can conclude by \Cref{first-cech-scott-continuity}.

\end{proof}

Now we conclude the vanishing of the usual cohomology groups for Stone spaces. 

\begin{proposition}\label{vanishing-first-stone}
Assume given a Stone space $S$ and for each $x:S$ an overtly discrete group $G(x)$. Then $H^1(S,G) = 0$.
\end{proposition}

\begin{proof}
  Let us consider $\alpha:H^1(S,G)$. By local choice there is a family $T(x)$ of inhabited Stone space depending on $x:S$ with $\|\Pi_{x:S}\Pi_{t:T(x)} (\alpha = 1) \|$, so $\alpha$ is in $H^1(S,T,G)$. But by \Cref{non-abelian-chech-is-sheaf-generic} we have $H^1(S,T,G) = \check{H}^1(S,T,G)$ and by \Cref{cech-vanishing-first-stone} we have $\check{H}^1(S,T,G) = 0$, so that $\alpha=1$.
\end{proof}

Finally, we conclude that the \v{C}ech cohomology agree with usual cohomology for compact Hausdorff spaces.

\begin{proposition}\label{non-abelian-cech-and-sheaf-agree}
Assume given a compact Hausdorff space $X$, a surjection $S\twoheadrightarrow X$ with $S$ Stone and for each $x:X$ an overtly discrete group $G(x)$. Then $H^1(X,G) = \check{H}^1(X,S,G)$.
\end{proposition}

\begin{proof}
From \Cref{vanishing-first-stone} and \Cref{non-abelian-chech-is-sheaf-generic-ayclic-cover}.
\end{proof}



\subsection{Vanishing of higher cohomology for Stone spaces}
\label{vanishing-stone}

The goal of this section is to extend \Cref{vanishing-first-stone} to higher cohomology groups. We proceed by induction on the cohomology index, which requires to strengthening the result to delooping of overtly discrete abelian groups commuting with Stone-indexed $\Pi$-types. First we present some preliminary results and definitions that works in plain HoTT.

%To be more specific, we will show in 
%\Cref{eilenberg-exponentials} that the following maps $\epsilon_n^{S,A}$ is an equivalence:
\begin{definition}
  Assume given $n:\N$ and a type $S$ with for each $x:S$ an abelian group $A(x)$. We write $\epsilon_n^{S,A}$ for the canonical map from $\K(\Pi_{x:S}A(x),n)$ to $\Pi_{x:S}\,\K(A(x),n)$.
\end{definition}

Our goal is then to show that $\epsilon_n^{S,A}$ is an equivalence when $S$ is Stone and each $A(x)$ is overtly discrete. 

\begin{lemma}\label{ev-eq-acyclic}
  Assume given $n\geq 1$ and a type $S$ with for each $x:S$ an abelian group $A(x)$. If $\epsilon_n^{S,A}$ is an equivalence, then $H^n(S,A) = 0$. 
\end{lemma}

\begin{proof}
  If $\epsilon_n^{S,A}$ is an equivalence then
  $H^n(S,A) = \propTrunc{\Pi_{x : S}\, \K(A(x),n)}_0 = \propTrunc{\K(\Pi_{x : S} A(x) , n)}_0$
  which is contractible because $n\geq 1$. 
\end{proof}

\begin{lemma}\label{ev-embedding}
  Assume given $n:\N$ and a type $S$ with for each $x:S$ an abelian group $A(x)$. If $\epsilon_n^{S,A}$ is an equivalence, then $\epsilon_{n+1}^{S,A}$ is an embedding. 
\end{lemma}

\begin{proof}
  The source is pointed and connected, so it is enough to prove the induced map
  \[\Omega(\K(\Pi_{x:S}A(x),n+1)) \to \Omega(\Pi_{x:S}\, \K(A(x),n+1))\]
  is an equivalence, where $\Omega$ denotes the loop space. But this map is equal to the canonical map
  \[\epsilon_n^{S,A} : \K(\Pi_{x:S}A(x),n) \to \Pi_{x:S}\,\K(A(x),n)\]
  which is assumed to be an equivalence.
\end{proof} 

\begin{lemma}\label{acyclic-ev-surjective}
  Assume given $n\geq 1$ and a type $S$ with for each $x:S$ an abelian group $A(x)$. If $H^n(S,A) = 0$, then $\epsilon_{n}^{S,A}$ is a surjection.
\end{lemma}

\begin{proof}
  Since $\K(\Pi_{x:S}A(x),n)$ is inhabited, it is enough to show that $\Pi_{x : S}\, \K(A_x,n)$ is $0$-connected, 
  which exactly means that $H^{n}(S,A)=0$. 
\end{proof}

\begin{theorem}\label{eilenberg-exponentials}
Assume given $n:\N$ and a Stone space $S$ with for each $x:S$ an overtly discrete abelian group $A(x)$. Then the map $\epsilon_n^{S,A}$ is an equivalence.
\end{theorem}

\begin{proof}
  We proceed by induction on $n$. For $n=0$ it is clear.
  
  Now assume the result holds for some $n:\N$.
  
  By this induction hypothesis and \Cref{ev-embedding}, we have that $\epsilon_{n+1}^{S,A}$ is an embedding. We just need to prove that it is surjective to conclude, and by \Cref{acyclic-ev-surjective}, it's sufficient to show that $H^{n+1}(S,A) = 0$. For $n=0$ this is the abelian version of \Cref{vanishing-first-stone}. 
  
  Now we assume $n\geq 1$. Assume given $\alpha:H^{n+1}(S,A)$, by local choice and \Cref{CechConditionEquivalentStatement} there exists a family of inhabited Stone spaces $(T(x))_{x:S}$ such that $\pi^*(\alpha) : H^{n+1}(\Sigma_{x:S}T(x), A\circ\pi)$ is $0$, where $\pi:\Sigma_{x:S}\,T(x)\to S$ is the first projection. Consider the factorisation of $\pi^*$ as
  \[ H^{n+1}(S,A)\to H^{n+1}(S,\lambda x.A(x)^{T(x)}) \to H^{n+1}(\Sigma_{x:S}T(x), A\circ\pi). \]
  We will show that both maps are injective, which will imply $\alpha=0$.

\begin{itemize}
 \item For each $x:S$ we define an abelian group $L(x)$ by the exact sequence
  \[  0\to A(x) \to A(x)^{T(x)} \to L(x) \to 0. \]
The long exact cohomology sequence then gives exactness of
\[ H^n(S,L)\to H^{n+1}(S,A)\to H^{n+1}(S,\lambda x. A(x)^{T(x)}).\]
By \Cref{tychonov-dual-stone} we get that $L(x)$ is a quotient of overtly discrete groups, and therefore overtly discrete. So by the induction hypothesis and \Cref{ev-eq-acyclic} we have that $H^n(S,L)=0$. Then the first map in the factorisation is indeed injective.
\item By the induction hypothesis and \Cref{ev-embedding}, for all $x:S$ the map $\epsilon_{n+1}^{T(x),A(x)}$ is an embedding. So the second map in the factorisation is indeed injective. 
\end{itemize}
\end{proof}

\begin{corollary}\label{vanishing-cohomology-stone}
Assume given $n\geq 1$ and a Stone space $S$ with for each $x:S$ an overtly discrete abelian group $A(x)$. Then $H^n(S,A) = 0$.
\end{corollary}



\subsection{\v{C}ech cohomology for compact Hausdorff spaces}
\label{cech-sheaf-agree-section}

\begin{definition}\label{dfnCech}
Assume given a type $X$ with $Y(x)$ an inhabited type and $A(x)$ an abelian group both depending on $x:X$. We define its \v{C}ech sequence $\check{C}(X,Y,A)$ as:
\[\Pi_{x:X}A(x)^{Y(x)} \overset{\delta_1}{\longrightarrow} \Pi_{x:X}A(x)^{Y(x)^2} \overset{\delta_2}{\longrightarrow} \Pi_{x:X}A(x)^{Y(x)^3} \overset{\delta_3}{\longrightarrow} \cdots \]
with:
\[\delta_n(\alpha)_x(y_0,\cdots,y_n) = \Sigma_{i=0}^n (-1)^i \alpha(y_0,\hdots,\hat{x_i},\hdots,y_n)\]
We have that $\delta_{n+1} \circ \delta_n = 0$.
%
We define the $n$-th \v{C}ech cohomology group $\check{H}^n(X,Y,A)$ as the $n$-th cohomology group of this chain complex.
\end{definition}

In \Cref{abelian-higher-cech}, we prove some technical general results about the \v Cech cohomology. Our main interest result is the following: 
\begin{theorem}\label{cech-and-sheaf-agree}
  Assume given $X:\CHaus$ with $q:S \twoheadrightarrow X$ a surjection from a Stone space, and $A(x)$ an overtly discrete abelian group. Then $H(X,A) = \check H^n(X,\lambda x. q^{-1}(x),A)$. 
\end{theorem}
\begin{proof}
  By \Cref{CechCoverSystemCohomologyAgree}, it is sufficient to note that by \Cref{tychonov-dual-stone}, \Cref{overtly-discrete-closure} and \Cref{vanishing-cohomology-stone}, $(\lambda x . q^{-1}(x),A)$ is a \v Cech cover system for $\mathcal A$ the class of overtly discrete abelian group depending on $X$.
\end{proof}

 
\subsection{The unit interval is acyclic}
\label{interval-acyclic}
This section extends \cite[Section 5.4]{synthetic-stone-duality}. 
\begin{remark}
  Recall from \parencite[Section 4.4]{synthetic-stone-duality} that for each $n:\N$, we can define $cs_n: 2^n \to Q$ by $cs_n(\alpha) = \sum\limits_{i<n} \frac{\alpha(i)}{2^{i+1}}$. And for $\I = [0,1]$ the interval of Cauchy or Dedekind reals, we can define $cs: 2^\N \to \I$ by $cs(\alpha) = \lim\limits_{n\to\infty} cs_n(\alpha|_n)$. This function witnesses that $\I$ is compact Hausdorff. 
\end{remark}

\begin{lemma}\label{interval-connected}
Given $I$ a finite type, any map from $\I$ to $I$ is constant.
\end{lemma}

\begin{proof}
We consider the map $p : 2^\N\to\I\to I$, by \Cref{factorisation-stone-finite} it factors through $2^n$ for some $n:\N$. 

Let us prove that for all $k:\N$, if the map factors through $2^{k+1}$ as $p_{k+1}$ then it factors through $2^k$. Consider $\alpha:2^k$, then since $p$ factors through $\I$, it respects $\sim_{k}$. So we have that $p(\alpha,1,0,0,\hdots) = p(\alpha,0,1,1,\hdots)$ so that $p_{k+1}(\alpha,0) = p_{k+1}(\alpha,1)$, and $p_{k+1}$ indeed factors through $2^k$, therefore so does $p$.

From this we get that $p$ factors through $2^0$, so it is indeed constant.
\end{proof}

The following definition allows us to study the fibers of $cs$ as a chain complex. As this is a general combinatorial approach, we present the results as appendix in \Cref{combinatorialIntervalSection}.
\begin{definition}\label{description-Cn-simn}
  Define $\mathbb I_n^{\sim k}$ to be 
  the type of $k+1$-tuples of binary sequences in $2^n$ such that for any $a,b:2^n$ in the tuple, we have 
  $|cs_n (a) -cs_n(b) |\leq\frac1{2^n}$. 
  Note that there are at most two such sequences, that 
  $\mathbb I_n^{\sim k}$ is Stone, and that
  $$\Sigma_{x : \mathbb I} (cs^{-1}(x))^{k+1} = \lim_{n} \mathbb I_n^{\sim k}.$$
\end{definition}






\begin{theorem}\label{cohomology-I}
The unit interval is acyclic, in the sense that:

\begin{enumerate}[(i)]
\item Given $I$ an overtly discrete type, any map in $\I\to I$ is constant.
\item Given $G$ an overtly discrete group, we have that $H^1(\I,G) = 0$.
\item Given $A$ an overtly discrete abelian group, we have that $H^n(\I,A) = 0$ for $n\geq 1$.
\end{enumerate}
\end{theorem}

\begin{proof}
We prove each point as follows:

\begin{enumerate}[(i)]

\item Given a map $p:\I\to I$, we write $I=\mathrm{colim}_jI_j$ with $I_j$ finite. By \Cref{scott-continuity-chaus} we know that $p$ factors through $I_k$ for some $k$, but by \Cref{interval-connected} any map from $\I$ to $I_k$ is constant so $p$ is indeed constant.

\item Consider $cs:2^\N\to\I$ and the associated \v{C}ech cover $T$ of $\I$ defined by: 
\[T(x) = \Sigma_{y:2^\N} (x=_\I cs(y))\]
Then we have that $\mathrm{lim}_n\I_n^{\sim l} = \Sigma_{x:\I} T(x)^l$. 
By \Cref{LemmaExactnessIntervalApproxFirstTerms} and stability of exactness under sequential colimit, we have an exact sequences:
\[ \mathrm{colim}_n G^{\I_n} \to \mathrm{colim}_n G^{\I_n^{\sim2}}\to \mathrm{colim}_n G^{\I_n^{\sim3}}\]
By \cref{scott-continuity-left} this sequence is equivalent to
\[\Pi_{x:\I}G^{T(x)} \to  \Pi_{x:\mathbb{I}}G^{T(x)^2} \to  \Pi_{x:\mathbb{I}}G^{T(x)^3}\]
So it being exact implies that $\check{H}^n(\I,T,G) = 0$ for $n\geq 1$.
We conclude by \Cref{non-abelian-cech-and-sheaf-agree}.

\item Same as point (ii) using \Cref{cech-and-sheaf-agree} instead of \ref{non-abelian-cech-and-sheaf-agree} and \Cref{LemmaExactnessIntervalApproxLaterTerms} in addition to \ref{LemmaExactnessIntervalApproxFirstTerms}. 

\end{enumerate}
\end{proof}

We give an example of application of the non-abelian \v Cech cohomology. Recall that a type $X$ is $\I$-local if the map $X\to X^\I$ is an equivalence.

\begin{lemma}\label{delooping-I-local}
We have the following:
\begin{enumerate}[(i)]
\item Any overtly discrete type is $\I$-local.
\item Given $G$ an overtly discrete group, we have that $BG$ is $\I$-local.
\item Given $A$ an overtly discrete abelian group and $n:\N$, we have that $K(A,n)$ is overtly discrete.
\end{enumerate}
\end{lemma}

\begin{proof}
As follows:

\begin{enumerate}[(i)]
\item From \Cref{cohomology-I}(i).
\item Identity types in $BG$ are $G$-torsors, therefore they are $\I$-local by (i), so the map $BG\to BG^\I$ is an embedding. It is surjective by \Cref{cohomology-I}(ii).
\item By induction on $n:\N$, the case $n=0$ is point (i). Assume it holds for $n\geq 0$, then identity types in $K(A,n+1)$ are $K(A,n)$-torsors, therefore they are $\I$-local by induction hypothesis, so the map $K(A,n+1)\to K(A,n+1)^\I$ is an embedding. It is surjective by \Cref{cohomology-I}(iii).
\end{enumerate} 
\end{proof}

\begin{proposition}
Assume given $X$ a type such that:

\begin{itemize}
\item $X$ is Postnikov complete (i.e. $\mathrm{lim}_k\propTrunc{X}_k = X$).
\item $\propTrunc{X}_0$ is overtly discrete.
\item For all $x:X$ and $n\geq 1$, we have that $\pi_n(X,x)$ is overtly discrete.
\end{itemize}
Then $X$ is $\I$-local.
\end{proposition}

\begin{proof}
By Postnikov completion it is enough to prove that $\propTrunc{X}_n$ is $\I$-local for all $n:\N$. We proceed by induction on $n:\N$. 

For $n=0$ this is \Cref{delooping-I-local}(i).

For $n=1$ we have a map $\propTrunc{X}_1\to \propTrunc{X}_0$, from the $n=0$ case we just need to prove its fibers are $\I$-local. But they merely are of the form $B\pi_1(X,x)$ for some $x:X$, so we conclude by \Cref{delooping-I-local}(ii). 

Assuming this holds for $n\geq 1$, we have a map $\propTrunc{X}_{n+1}\to \propTrunc{X}_n$. By the induction hypothesis we just need to prove its fibers are $\I$-local to conclude that $\propTrunc{X}_{n+1}$ is $\I$-local. But the fibers are merely of the form $K(\pi_{n+1}(X,x),n+1)$ for some $x:X$, so we conclude by \Cref{delooping-I-local}(iii). 
\end{proof}
